# USER STORIES

## 1. Report a Lost Item

**As a student who has lost an item, I want to report the item through the application so that there is a centralized record of my lost belonging.**

## **Reason:** All five participants identified reporting lost items as an important feature, while the absence of a central reporting system was the biggest challenge.

## 2. Report a Found Item

**As a student who has found an item, I want to report it through the application so that the owner can have a better chance of recovering it.**

**Reason:** Four participants had found items belonging to other students, but their actions varied because there was no organized reporting mechanism.

---

## 3. Upload an Item Photo

**As a student, I want to upload a photo of a lost or found item so that other users can identify the item more easily.**

**Reason:** All five participants selected photo uploads as an important feature.

---

## 4. Search by Category

**As a student looking for a lost item, I want to search by item category so that I can find relevant items more quickly.**

**Reason:** Three participants selected category-based search as an important feature.

---

## 5. Search by Location

**As a student, I want to search for an item by location so that I can find items reported around the area where I lost or found something.**

**Reason:** Two participants selected location-based search as an important feature.

---

## 6. Receive Notifications

**As a student who has reported a lost or found item, I want to receive notifications about updates so that I do not have to repeatedly check the application.**

**Reason:** Notifications were selected by all five participants and received an average importance rating of 4.8 out of 5.

---

## 7. Track a Claim

**As a student claiming an item, I want to track my claim status so that I know whether there has been progress on my request.**

**Reason:** Four participants selected claim tracking as an important feature.

---

## 8. Securely Log In

**As a student, I want to securely log into the application so that my account and lost-and-found information are protected.**

**Reason:** Three participants selected secure user login as an important feature.

---

## 9. Chat with the Finder

**As a student who has found or is claiming an item, I want to communicate with the other party so that I can clarify information about the item.**

**Reason:** Three participants selected chat with the finder as an important feature.

---

## 10. Use a Simple Interface

**As a student, I want the application to be simple and intuitive so that I can report, search for, or claim an item without difficulty.**

**Reason:** All five participants rated the desired ease of use at 5 out of 5, indicating that a simple and intuitive interface is important.
