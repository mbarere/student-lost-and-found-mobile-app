# Student Lost-and-Found Questionnaire

## Description

This questionnaire was created using Google Forms to collect user feedback for the Student Lost-and-Found Mobile Application.

## Google Forms Link

[Open the Student Lost-and-Found Questionnaire](https://docs.google.com/forms/d/e/1FAIpQLSenVETw5ye09OiW4duYXgIRftN_4BNFYglAeGu4ALMVk2XuQg/viewform?usp=sharing)

## Purpose

The questionnaire aims to understand students' experiences with lost and found items on campus and identify user requirements for the proposed mobile application.
