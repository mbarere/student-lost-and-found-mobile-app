# Questionnaire Analysis

This folder contains the results obtained from the user research conducted for the Student Lost-and-Found Mobile Application.

## Documents

### 1. Analysis of Questionnaire Results
This document presents the analysis of responses collected from participants. It includes demographic information, identified trends, key findings, and interpretation of the questionnaire data.

### 2. Research Summary
This document summarizes the entire user research process, including the research objective, methodology, participant information, major findings, recommendations, and conclusion.

These documents provide evidence of the user research conducted during the requirements gathering phase of the project.
