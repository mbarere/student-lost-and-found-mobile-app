# Student Lost and Found Mobile App

Overview

This project is a Human-Computer Interaction (HCI) group assignment aimed at designing a mobile application prototype using Balsamiq.

The application enables students to report lost items, report found items, search for missing belongings, and submit ownership claims through an easy-to-use mobile interface.

---

Objectives

- Improve recovery of lost property on campus.
- Reduce reliance on notice boards and social media.
- Provide an easy mobile reporting system.
- Improve communication between finders and owners.

---

## Target Users

- Students
- Lecturers
- Security Officers
- Hostel Wardens
- Visitors
